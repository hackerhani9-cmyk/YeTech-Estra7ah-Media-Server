# YeTech Estra7ah Media Server

This monorepo contains a local media server and a responsive RTL frontend for LAN/Wi‑Fi use.

## Quick Start on Replit

1. Open the project in Replit.
2. In the shell run:

```bash
npm install
npm run dev
```

3. Open the frontend URL exposed by Replit (usually `http://localhost:5173`).
4. The backend API runs on `http://localhost:4000`.

## Features

- Express.js backend with SQLite
- React + Vite frontend
- RTL Arabic UI
- Admin settings and branding customization
- Smart AI episode tracking
- Local HTTP 206 streaming
- Live stream section
- Responsive design for phones, tablets, laptops, and smart TVs
